📐 核心公式速查

#公式名称公式
①BEP产量BEP(Q) = 固定成本 / (单价 - 单位可变成本 - 单位税金及附加)
②BEP生产能力利用率BEP(%) = BEP(Q) / 设计年产销量 × 100%
③BEP售价BEP(P) = 固定成本 / 设计年产销量 + 单位可变成本 + 单位税金及附加
④安全阈量安全阈量 = 设计年产销量 - BEP(Q)
⑤安全阈值安全阈值 = 1 - BEP(%) （一般应 ≥ 30%，即BEP(%)≤70%）
⑥敏感度系数S = (ΔA/A) / (ΔF/F)
⑦临界点（绝对测定法）使项目由可行转为不可行的不确定因素临界数值

BEP(%)=BEP(Q)/设计产销量×100%，安全阈值一般以70%为界。
