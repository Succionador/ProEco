# ProEco — 26经济章节题

2026年一级建造师《建设工程经济》刷题系统，纯前端静态实现，无需服务器。

## 功能特性

- 章节选择首页：20章目录，清晰展示进度
- 一页一题：专注答题，避免干扰
- 实时计分：单选对1分，多选按规则计分
- 断点续做：localStorage 自动保存进度
- 错题重做：一键重做错题，支持选择性重练
- 分类筛选：全部/单选/多选/未答/错题
- MathJax 公式渲染：数学公式正确显示
- Markdown 表格渲染：现金流量表等表格正确显示
- 响应式设计：适配桌面和移动端

## 使用方式

- 直接打开 index.html 即可使用
- 或部署到任意静态服务器（GitHub Pages、Vercel 等）

## 第5章【价值工程】知识点框架

### 一、价值工程的含义
- 价值工程的计算公式：$V = F/C$
- 寿命周期成本：研究 + 形成 + 退出使用的全部费用
- "工程"是指为提高对象价值所进行的一系列活动

### 二、价值工程的特点（7个）
1. 有效实现对象技术和经济的结合
2. 基于用户/顾客（消费者）视角解决问题
3. 目标是提高对象的价值
4. 价值工程活动的核心是功能分析
5. 价值工程应致力于技术方案的创新
6. 需要有量的界定和分析
7. 是一种有计划、有组织的管理活动

### 三、提高价值的途径（5种）
- 双向型：功能 $F\uparrow$，费用 $C\downarrow$
- 改进型：功能 $F\uparrow$，费用 $C\rightarrow$
- 节约型：功能 $F\rightarrow$，费用 $C\downarrow$
- 投资型：功能 $F\uparrow\uparrow$，费用 $C\uparrow$
- 牺牲型：功能 $F\downarrow$，费用 $C\downarrow\downarrow$

### 四、对象选择方法
- 因素分析法（经验分析法）
- ABC分析法（百分比法，二八法则）
- 强制确定法（0-1评分法、0-4评分法）
- 百分比分析法（成本/费用维度）
- 价值指数法

### 五、功能分析
- 功能定义：明确各功能具体要求
- 功能整理：建立功能系统图（FAST图）
- 功能计量：4种表达方式（数量指标、等级、系数、强制确定量化）

### 六、功能评价
- 功能评价值 $F$（目标成本）
- 价值指数 $V = F/C$
- 成本改进期望值 $\Delta C = C - F$

### 七、方案创新与评价
- 方案创新方法：头脑风暴法、歌顿法、专家意见法、专家检查法
- 方案评价：技术评价、经济评价、社会评价、环境影响评价
- 概略评价：初步筛选
- 详细评价：具体化，最终选择
