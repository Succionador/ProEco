📖 本章知识框架

第5章 价值工程 5.1 价值工程概述 5.1.1 价值工程的含义 * 价值 V = F / C（功能/费用） * 寿命周期成本 = 研究+形成+退出使用的全部费用 5.1.2 提高价值的5种途径 * 双向型（功能↑，费用↓）-- 最理想 * 改进型（功能↑，费用→） * 节约型（功能→，费用↓） * 投资型（功能↑↑，费用↑） * 牺牲型（功能↓，费用↓↓） 5.1.3 价值工程的特点（7条） 5.2 价值工程实施步骤 5.2.1 准备阶段 * 对象选择 / 组成工作组 / 制订计划 5.2.2 分析阶段 * 收集资料 / 功能分析 / 功能评价 5.2.3 创新阶段 * 方案创新 / 方案评价 / 提案编写 5.2.4 实施阶段 * 四个落实：组织、经费、物资、时间 5.3 对象选择方法 5.3.1 因素分析法（定性） 5.3.2 ABC分析法（二八法则） 5.3.3 强制确定法（0-1评分/0-4评分） 5.3.4 百分比分析法（成本维度） 5.3.5 价值指数法（功能+成本） 5.4 功能分析 5.4.1 功能定义（动词+名词） 5.4.2 功能整理（上位=目的，下位=手段） 5.4.3 功能计量（数量/等级/系数/强制确定） 5.4.4 功能分类 * 按重要程度：基本功能 / 辅助功能 * 按使用性质：使用功能 / 品位功能 * 按用户需求：必要功能 / 不必要功能 * 按相对需求：不足功能 / 过剩功能 5.5 功能评价 5.5.1 价值指数 V = F / C * V=1：匹配理想，无需改进 * V<1：成本过高，应优先改进 * V>1：成本偏低，需具体分析 5.5.2 成本改进期望值 ΔC = C - F 5.6 方案创新与评价 5.6.1 方案创新方法（头脑风暴/歌顿/德尔菲/专家检查） 5.6.2 方案评价（概略评价+详细评价） 5.6.3 评价内容（技术/经济/社会/环境）

📐 核心公式速查

#公式名称公式
1价值指数$V = \dfrac{F}{C}$
2成本改进期望值$\Delta C = C - F$
3功能评价值$\text{功能评价值} = \text{初始总成本} \times \text{重要性系数}$

V=价值指数；F=功能评价值；C=目前成本；ΔC=成本改进期望值
