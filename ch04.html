📐 核心公式速查

#公式名称公式
1经济寿命（劣化值公式）$N_0 = \sqrt{\dfrac{2(P-L)}{\lambda}}$
2年平均使用成本$\\bar{C} = (P-L_n)/N + \\bar{C}$
3设备劣化（等差递增）$C_t = C_1 + (t-1)\\lambda$
4沉没成本= 账面价值 - 市场价值
5旧设备投资额（第三方）= 市场价值 + 升级维修费
6费用年值法$AC = P(A/P,i,n) + C - L(A/F,i,n)$
7附加率法租金$R = P(1+i\\cdot N)/N + P\\cdot r$
8年金法（期末支付）$R = P\\cdot i(1+i)^n / [(1+i)^n - 1]$
9年金法（期初支付）$R_{期初} = R_{期末} / (1+i)$

P=设备实际价值；L=净残值；λ=劣化值；C̄=年平均运行成本；C=年运行成本；i=利率/折现率；N/n=使用年限；r=附加率
