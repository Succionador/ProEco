第2章 经济效果评价

  2.1 经济效果评价的内容
     * 评价的基本内容
       - 盈利能力分析（最重要）
       - 偿债能力分析
       - 财务生存能力分析
     * 经营性项目 vs 非经营性项目
     * 财务生存能力的两个基本条件
  2.2 经济效果评价指标体系
     * 静态评价指标（不考虑时间价值）
       - 投资收益率（ROI）
       - 总投资收益率（ROI）
       - 资本金净利润率（ROE）
       - 静态投资回收期（Pt）
     * 动态评价指标（考虑时间价值）
       - 财务净现值（FNPV）
       - 财务内部收益率（FIRR）
       - 动态投资回收期（Pt'）
     * 偿债能力指标
       - 利息备付率（ICR）
       - 偿债备付率（DSCR）
       - 资产负债率
       - 流动比率 / 速动比率
  2.3 多方案比选
     * 独立方案 —— 绝对效果检验
     * 互斥方案 —— 相对效果检验 + 绝对效果检验
     * 增量投资收益率法
     * 增量投资回收期法
     * 净现值法 / 净年值法
     * 最小公倍数法 / 研究期法

📐 核心公式速查

#公式名称公式
①总投资收益率ROI = EBIT / TI × 100%
②资本金净利润率ROE = NP / EC × 100%
③静态投资回收期Pt = 累计净现金流量首次为正的年份-1 + |上年累计|/当年净流量
④判别准则Pt ≤ Pc（基准投资回收期） → 可行
⑤财务净现值FNPV = Σ(CI-CO)t(1+ic)⁻ᵗ
⑥FNPV判别准则FNPV ≥ 0 → 可行
⑦财务内部收益率Σ(CI-CO)t(1+FIRR)⁻ᵗ = 0
⑧FIRR判别准则FIRR ≥ ic → 可行
⑨利息备付率ICR = EBIT / PI
⑩偿债备付率DSCR = (EBITDA - Tax) / PD
⑪增量投资收益率R(2-1) = (C1-C2) / (I2-I1) × 100%
⑫增量投资回收期Pt(2-1) = (I2-I1) / (C1-C2)

EBIT=息税前利润; TI=总投资; EC=资本金; NP=净利润; PI=应付利息; EBITDA=息税折旧摊销前利润; PD=应还本付息额

📌 各节核心考点

2.1 评价内容：经营性项目分析盈利能力+偿债能力+财务生存能力。非经营性项目主要分析财务生存能力。财务生存的两个基本条件：有足够经营净现金流量、累计盈余资金不出现负值

2.2 评价指标体系：静态指标与动态指标的区别.FNPV与FIRR的计算与判别准则.Pt计算方法（插值法）.偿债能力各指标的基准值要求

2.3 多方案比选：独立方案vs互斥方案的检验方法.增量分析法的步骤.寿命期不同方案的比选方法（最小公倍数法、研究期法）
